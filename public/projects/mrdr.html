MRDR..

Jogo original de dedução criminal construído em torno de pistas, suspeitos, álibis e cronologias.

An original crime-deduction game built around clues, suspects, alibis and timelines.

ReactTypeScriptViteCapacitor
CONTEXTO

O problema

Um jogo de dedução precisa de pistas consistentes e informação suficiente para o jogador raciocinar, além de uma forma de validar se a solução é única.

ABORDAGEM

A solução

Jogo em desenvolvimento com casos estruturados e um motor de validação. O foco está na coerência lógica e na experiência de investigação, sem reproduzir puzzles ou identidade de outros jogos.

FUNCIONALIDADES

O que foi construído

  • Casos de dedução criminal com suspeitos, motivos e álibis.
  • Pistas interligadas, provas e cronologias para analisar.
  • Motor de dedução e validação de soluções únicas.
  • Progressão local, desafios diários, conquistas e caderno de investigação.
  • Aplicação Web instalável (PWA), com suporte offline descrito no projeto.
ESTADO ATUAL

Estado do projeto

Versão funcional concluída. A distribuição pública continua pendente: não existe uma demo Web pública ligada, o Android ainda não tem uma versão assinada nem submissão à Play Store, e o build iOS não foi validado.

PRÓXIMOS PASSOS

Evolução

Preparar uma demo Web pública, validar o jogo em dispositivos físicos, assinar e testar a versão Android e concluir a validação iOS em Xcode antes de qualquer submissão às lojas.

CONTEXT

The problem

A deduction game needs consistent clues and enough information for players to reason, along with a way to validate whether a solution is unique.

APPROACH

The solution

A game in development with structured cases and a validation engine. The focus is logical consistency and the investigation experience, without reproducing other games' puzzles or identity.

FEATURES

What was built

  • Crime-deduction cases with suspects, motives and alibis.
  • Connected clues, evidence and timelines to analyse.
  • Deduction engine and unique-solution validation.
  • Local progression, daily challenges, achievements and an investigator notebook.
  • Installable web app (PWA), with offline support described in the project.
CURRENT STATUS

Project status

Functional version complete. Public distribution is still pending: no public web demo is linked, Android has no signed release or Play Store submission yet, and the iOS build has not been verified.

NEXT STEPS

Further development

Prepare a public web demo, test gameplay on physical devices, sign and validate the Android release, and complete iOS validation in Xcode before any store submission.
