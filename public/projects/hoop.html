Frontend académico de uma loja online de basquetebol, com catálogo e percurso de compra simulado.

An academic frontend for a basketball store, with a product catalogue and simulated purchase journey.

ReactTypeScriptViteReact Router
Abrir demonstraçãoGitHub
CONTEXTO

O problema

Uma loja online precisa de ajudar as pessoas a encontrar produtos, comparar opções e compreender o percurso de compra.

ABORDAGEM

A solução

Interface de uma loja temática de basquetebol, com pesquisa, filtros, favoritos, carrinho e checkout simulado. Demonstra frontend, não pagamentos reais.

FUNCIONALIDADES

O que foi construído

  • Catálogo e páginas de produto.
  • Pesquisa e filtros.
  • Favoritos e carrinho.
  • Navegação com React Router.
  • Checkout simulado, sem processamento real de pagamentos.
ESTADO ATUAL

Estado do projeto

Projeto académico frontend. Não inclui backend comercial nem pagamentos reais.

PRÓXIMOS PASSOS

Evolução

Ligar a interface a uma API, implementar autenticação e persistência, validar acessibilidade e integrar um fluxo de pagamento de teste.

CONTEXT

The problem

An online store needs to help people find products, compare options and understand the purchase journey.

APPROACH

The solution

A basketball-themed store interface with search, filters, favourites, a cart and simulated checkout. It demonstrates frontend work, not real payments.

FEATURES

What was built

  • Product catalogue and product pages.
  • Search and filters.
  • Favourites and shopping cart.
  • Navigation with React Router.
  • Simulated checkout, with no real payment processing.
CURRENT STATUS

Project status

Academic frontend project. It does not include a commercial backend or real payments.

NEXT STEPS

Further development

Connect the interface to an API, add authentication and persistence, validate accessibility and integrate a test payment flow.
