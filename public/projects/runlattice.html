CONTEXTO

O problema

Automatizar tarefas entre ferramentas pode exigir conhecimentos de integrações, webhooks e estruturas de dados, criando uma barreira para utilizadores iniciantes.

ABORDAGEM

A solução

Protótipo que combina editor visual e modelos com opções avançadas. A IA propõe rascunhos de workflows que precisam de revisão antes de qualquer ativação.

FUNCIONALIDADES

O que foi construído

  • Workspaces e editor visual de workflows.
  • Modelos para acelerar a configuração.
  • Execução assíncrona com Redis e BullMQ.
  • Webhooks assinados e agendamentos.
  • Ação externa funcional para enviar mensagens para webhooks Discord.
  • Planeamento por IA como rascunho sujeito a revisão.
  • Checkout, portal de cliente e webhooks Stripe para subscrições e permissões por plano, ainda a validar end-to-end.
ESTADO ATUAL

Estado do projeto

Protótipo em desenvolvimento, não preparado para produção. Discord é a única ação externa funcional. O worker suporta um trigger e, no máximo, uma condição. Os fluxos de faturação Stripe estão implementados, mas ainda aguardam validação com credenciais sandbox e testes end-to-end.

PRÓXIMOS PASSOS

Evolução

Validar os fluxos Stripe em sandbox, expandir integrações, aprofundar o motor de execução e reforçar observabilidade, permissões, gestão de erros e testes.

CONTEXT

The problem

Automating tasks across tools can require knowledge of integrations, webhooks and data structures, creating a barrier for beginners.

APPROACH

The solution

A prototype combining a visual editor and templates with advanced options. AI proposes workflow drafts that must be reviewed before activation.

FEATURES

What was built

  • Workspaces and a visual workflow editor.
  • Templates to speed up setup.
  • Asynchronous execution with Redis and BullMQ.
  • Signed webhooks and scheduling.
  • One working external action that sends messages to Discord webhooks.
  • AI workflow planning as a reviewable draft.
  • Stripe Checkout, Customer Portal and subscription webhooks for plan entitlements, still awaiting end-to-end validation.
CURRENT STATUS

Project status

Prototype in development and not production-ready. Discord is the only live external action. The worker supports one trigger and at most one condition. Stripe billing flows are implemented but still require sandbox credentials and end-to-end testing.

NEXT STEPS

Further development

Validate Stripe flows in sandbox, expand integrations, improve the execution engine, observability, permissions, error handling and testing.
