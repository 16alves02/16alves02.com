# 16alves02 Portfolio

Personal portfolio for Leonardo Alves, built with React and Vite.

## Run locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

## Features

- Responsive layout for desktop, tablet and mobile.
- Light and dark themes, with the selected mode saved locally.
- Language selector with English as the default, plus Portuguese (Portugal), Spanish, French, Italian, German and Japanese. The active language is marked in the dropdown and the selection is saved locally.
- Brand orange `#EB4520` with neutral paper, charcoal and grey surfaces. No pink is used as a site accent.
- Transparent LA logo in `public/logo.png`.
- Project links to the public demos and GitHub repositories.
- Contact by email and social links provided for the 16alves02 accounts.

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Import that repository in Vercel.
3. Use the Vite preset, `npm run build` as the build command, and `dist` as the output directory.
4. Deploy to the provided `vercel.app` domain. Connect `16alves02.com` later, after purchasing the domain.

## Content choices

- No phone number or exact town is published.
- Only the relevant web development experience is included, with concise descriptions.
- SaborGest is identified as an academic project in development.
- The portfolio prioritizes projects, relevant skills, education, internship availability and public professional/social links.
