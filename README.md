# 16alves02 Portfolio

Source code for my personal portfolio, built with React and Vite. It presents my projects, background, and ways to get in touch.

**[View the live portfolio](https://16alves02-com.vercel.app)**

## Features

- Responsive layout for desktop, tablet and mobile.
- Light and dark themes, with the selected theme saved locally.
- Language selector with English as the default, plus Portuguese (Portugal), Spanish, French, Italian, German and Japanese. The active language is marked in the dropdown and the selection is saved locally.
- Orange brand colour `#EB4520`, paired with neutral paper, charcoal and grey surfaces.
- Transparent LA logo at `public/logo.png`.
- Links to public project demos and GitHub repositories.
- Contact by email and links to professional and social accounts.

## Run locally

You need Node.js and npm installed.

```bash
git clone https://github.com/16alves02/16alves02.com.git
cd 16alves02.com
npm install
npm run dev
```

Vite will display the local development URL in the terminal.

## Production build

Create a production build and preview it locally:

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push the project to a GitHub repository.
2. Import the repository into Vercel.
3. Use the Vite preset, `npm run build` as the build command, and `dist` as the output directory.
4. Deploy to the generated `vercel.app` domain. A custom domain can be connected in Vercel when available.

## Content choices

- No phone number or exact location is published.
- Only relevant web development experience is included, with concise descriptions.
- SaborGest is presented as an academic project that is still in development.
- The portfolio prioritizes projects, relevant skills, education, internship availability and public professional/social links.
